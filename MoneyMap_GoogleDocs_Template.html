1. Project Overview

MoneyMap is an intelligent mobile personal finance application built to help users manage their money by creating flexible budgets on Weekly, Monthly, or Yearly bases. The app delivers intuitive, real-time visual representations of how much money has been spent and provides immediate visual awareness of how much budget remains.

Equipped with automated AI receipt scanning, dual-token security architecture, and category-level spending tracking, MoneyMap bridges the gap between everyday expenses and long-term financial discipline.

2. Key Features

  • Flexible Multi-Cycle Budgeting: Set up and track budgets on weekly, monthly, or annual intervals tailored to specific income streams or goals.
  • Visual Spend vs. Remaining Gauge: Dynamic progress rings, charts, and color-coded threshold statuses (Safe Green, Warning Amber, Over-budget Red) displaying spent amounts vs remaining balance in real time.
  • Smart Receipt Scanning (OCR): Capture receipts via camera or gallery; automatically extracts merchant name, date, items, and totals for instant review and logging.
  • Custom & Default Categories: Organize spending into distinct categories with custom icons and color tags.
  • Detailed Transaction Filtering: Comprehensive query engine supporting filtering by date range, transaction type (income vs. expense), category, and budget association.
  • Secure Dual-Token Authentication: 15-minute JWT Access Tokens paired with 30-day Refresh Tokens stored via hardware-backed expo-secure-store, featuring transparent Axios interceptors for background token refresh.

3. Architecture & Technology Stack

MoneyMap implements a decoupled Client-Server Layered Architecture with containerized persistence:

Layer Technology Role & Details
Mobile Client React Native (Expo SDK 54), TypeScript 5.9 Cross-platform native iOS & Android app using Expo Router v6 file-based navigation.
Client State Zustand v5 & TanStack React Query v5 Zustand state machine for Auth & Settings; React Query for caching and optimistic UI updates.
Styling NativeWind (Tailwind CSS v4) Clean, responsive design system based on a modern Soft Violet palette.
Backend API Node.js, Express, RESTful APIs Handles authentication, business logic, analytics calculations, and OCR processing.
ORM & Modeling Prisma ORM Type-safe query building, relational schema modeling, and migration automation.
Database PostgreSQL ACID-compliant relational database ensuring financial data integrity.
Containerization Docker & Docker Compose Containerized PostgreSQL environment ensuring zero-friction local and cloud deployments.

4. Software Engineering Principles Applied

  • SOLID Principles:
    • Single Responsibility Principle (SRP): Separation between UI presentation, React Query hooks, and business domain layers.
    • Open/Closed Principle (OCP): Extendable category systems and period calculators without changing core ledger engines.
    • Dependency Inversion Principle (DIP): Modules depend on abstract hook interfaces rather than raw HTTP clients.
  • Separation of Concerns (SoC): Strict isolation between presentation logic, application state, and backend database queries.
  • Resilient Network & Concurrency Guard: Implemented Axios queue interceptors that hold concurrent 401 requests during token rotation to avoid race conditions.
  • Infrastructure as Code & Isolation: Dockerized database stack guarantees reproducible environments across machines.
  • Defense in Depth: Hardware-backed keychain storage, bcrypt hashing, and parameterized ORM queries to prevent injection vulnerabilities.
